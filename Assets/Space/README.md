# Generated periodic space backgrounds

Generated with the built-in image generation tool for this project on 2026-11-01. These are new nebula/star plates, not edits of third-party artwork. PNG originals are shared native/Godot source assets; the browser uses derived WebP copies produced by `Web/scripts/prepare-space-assets.mjs`.

The runtime uses original-orientation periodic tiles with a narrow overlapping edge fade to absorb residual edge/compression differences. There is **no mirrored composition**. Stations, wrecks, asteroids and ships are separate layers and physical objects.

## Prompt set

Common production specification: stylized-concept, landscape 16:9, cinematic detailed realistic painted science-fiction space art. A truly seamless periodic horizontal and vertical deep-space texture for endless UV scrolling without reflection or bilateral symmetry. Left/right and top/bottom edges continue naturally. Quiet combat-readable composition, sparse tiny sharp stars, no borders, vignette, edge framing or central focal object. No planets, suns, ships, stations, wrecks, rocks, foreground objects, horizon, text or UI; those belong to independent procedural layers.

- **rift.png:** Nearly black purple space, ethereal restrained violet and emerald-green thin gas clouds, readable dark open areas across the center.
